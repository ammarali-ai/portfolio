## Overview

A computer-vision pipeline for detecting diseases in rice leaves, comparing several modeling approaches and validating against a large image dataset.

## Highlights

- Built a CNN-based model using TensorFlow and Keras, achieving **92% accuracy**.
- Evaluated multiple algorithms including CNN, SVM, transfer learning, and random forest.
- Processed over **10,000 images** using OpenCV for robust model validation.

## Tech Stack

TensorFlow · Keras · OpenCV · CNN · Transfer Learning · SVM · Random Forest
